# 폰에서 확인할 것 (배포할 때마다 5분)

Claude가 자동 테스트로 확인하지 못하는 건 "진짜 폰에서의 느낌"입니다. 새 버전을 열 때마다 아래 다섯 가지만 봐 주세요. 이상하면 어느 번호에서 무엇이 이상했는지만 알려주시면 됩니다.

1. **진입** — 처음 열면 닉네임 칸에 추천 이름이 채워져 있나요? 직접 바꿔 "해변으로 가기"를 누르면 해변으로 들어가나요? (두 번째부터는 바로 해변)
2. **걷기** — 화면 왼쪽 아래를 누르고 끌면 캐릭터가 그 방향으로 부드럽게 걷나요? 손을 떼면 멈추나요? 오른쪽을 끌면 카메라가 돌아가나요? 버벅이면 처음 3초 뒤 "부드럽게 보이도록 그래픽을 낮췄어요"가 떴는지도 알려주세요.
3. **석양멍** — "석양멍하기"를 누르면 UI가 사라지고 선베드에 누워 석양을 보나요? "파도 소리 켜기"를 누르면 소리가 나나요? "석양멍 끝내기"로 돌아오나요?
4. **병 띄우기** — "유리병 편지 쓰기" → 모양·글 → "바다에 띄우기" → 바다를 눌러 위치 → "여기에 띄우기" 후 병이 바다에 떠 있나요? "메시지 보기"에 나오나요?
5. **사진** — "사진찍기"를 누르면 공유 창(또는 사진 저장)이 뜨고, 사진 왼쪽 아래에 "Sunset Resort · 닉네임"이 찍혀 있나요?

함께 알려주시면 좋은 것: 폰 기종(예: 아이폰 15, 갤럭시 S23), 브라우저(사파리/크롬/삼성 인터넷).
