# 21. 편지 카드 — 3D 바다의 병을 "누른다"는 것

바다에 떠 있는 병을 손가락으로 누르면 편지 카드가 열려요. 카드에서는 ♥, 답글, 신고를 할 수 있어요.
쉬워 보이지만 세 가지 질문이 숨어 있어요.

## 1) 화면의 한 점이 3D의 어느 병일까? — 레이캐스트

화면은 평평한데 바다는 3D예요. 그래서 **카메라에서 누른 점 방향으로 보이지 않는 광선(ray)을 쏴서**
처음 부딪히는 물체를 찾아요. 이걸 레이캐스트라고 해요(`src/scene/bottles3d.js`의 `pickBottle`).

- 누른 위치를 -1~1 범위의 좌표(NDC)로 바꿔요: 왼쪽 끝 -1, 오른쪽 끝 +1.
- `raycaster.setFromCamera(ndc, camera)`로 광선을 만들고, 병들과 부딪히는지 검사해요.
- 병은 여러 조각(유리·코르크·편지)으로 되어 있어서, 맞은 조각에서 **부모를 따라 올라가며** 병 id를 찾아요.
- 병이 작아서 손가락이 살짝 빗나갈 수 있어요. 그래서 직접 맞은 병이 없으면 **화면에서 28px 안의 가장 가까운 병**을 골라요.

반대 방향 계산도 있어요. `screenPos`는 3D 위치를 화면 좌표로 바꾸는 함수예요(`project`).
테스트는 이 함수로 "병이 화면 어디에 있는지" 계산해서 그 자리를 클릭해요.

## 2) 탭일까, 드래그일까?

같은 화면에서 조이스틱(왼쪽), 카메라 돌리기(오른쪽), 병 누르기가 함께 일어나요. 그래서 이렇게 정했어요.

- 손가락을 대고 **8px 넘게 움직이면** 드래그 → 병 고르기 취소
- **300ms 넘게** 누르고 있으면 → 병 고르기 취소
- 둘 다 아니면 "짧은 탭"으로 보고 병을 찾아요

## 3) 남이 쓴 글은 위험할 수 있다 — textContent

모두의 바다에서는 **모르는 사람이 쓴 글**이 내 화면에 떠요. 누군가 편지에
`<img src=x onerror="...">` 같은 글을 쓰면, `innerHTML`로 넣는 순간 브라우저가 그걸 **코드로 실행**해요.
이런 공격을 XSS라고 해요.

그래서 카드의 틀(버튼, 칸)만 `innerHTML`로 만들고, 닉네임·편지·답글은 전부 `textContent`로 넣어요.
`textContent`는 무엇이 들어와도 "글자"로만 보여줘요.
테스트(`남의 글(닉네임·편지·답글)에 태그가 있어도 글자로만 보인다`)로 이걸 확인해요.
일부러 `innerHTML`로 바꿔 봤더니 테스트가 바로 실패했어요(뮤테이션 검사).

## 신고는 어떻게 동작할까

- 실수로 누르는 걸 막으려고 **두 번 눌러야** 보내져요("신고" → "정말 신고할까요?").
- 보내면 서버에 신고 1개가 쌓이고, **내 폰에는 `reportedIds`로 기억**해요. 그래서 다시 열어도 내 바다에는 안 떠요.
- 서로 다른 기기에서 3번 신고되면 서버가 모두의 바다에서 숨겨요(17번 문서의 서버 규칙).

## 서버가 아플 때

♥나 답글이 실패하면 숫자와 목록은 **그대로** 두고 "잠시 후 다시 시도해 주세요"라고 알려줘요.
화면을 먼저 바꿔 놓고 실패하면 되돌리는 방식(낙관적 업데이트)도 있지만, 이 앱에서는 서버가 성공했다고 답한 뒤에만 바꿔요.
더 단순하고 화면이 거짓말을 하지 않아요.

## 덧붙임: 공유 링크 `#b=병id`로 열기

편지를 띄우면 받는 링크 끝에 `#b=병id`가 붙어 있어요. `#` 뒤(해시)는 서버로 가지 않고 **브라우저 안에서만** 읽혀서,
GitHub Pages 같은 정적 호스팅에서도 쓸 수 있어요.

- 해변에 들어오면(처음 온 친구는 이름을 정하고 들어온 뒤) 해시를 읽어서 그 병을 서버에서 받아요.
- 병이 있으면 **그 병의 x 위치 앞바다**로 카메라를 옮기고 카드를 열어요.
- 병이 없거나 3번 신고로 숨겨졌으면 "이 편지는 바다에서 사라졌어요", 서버가 안 되면 "바다 소식을 불러오지 못했어요".
- 처리한 뒤 `history.replaceState`로 주소에서 해시를 지워요. 안 지우면 새로고침할 때마다 카드가 또 열려요.
- `#b=abc`처럼 모양이 이상하면 서버에 묻지도 않고 무시해요(UUID 모양 검사).
- 앱을 켜 둔 채 링크만 바뀌면 `hashchange` 이벤트로 같은 일을 해요.
