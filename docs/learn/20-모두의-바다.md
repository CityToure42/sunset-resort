# 20. 모두의 바다 — 서버에서 받아 띄우기

`src/features/bottles.js`가 이제 폰 저장소 대신 서버 저장소(`RemoteBottleStore`)를 씁니다.

- **받아 오기(`refresh`)**: 해변에 들어오면 서버에서 최근 병 200개를 받아 띄우고, 그 뒤로 60초마다, 그리고 다른 앱에 갔다가 돌아왔을 때(`visibilitychange`) 다시 받습니다. 내가 신고한 병(`profile.reportedIds`)은 빼고 띄워요. 서버가 대답하지 않으면 지금 바다를 그대로 두고 "바다 소식을 불러오지 못했어요"를 **한 번만** 띄웁니다(1분마다 같은 알림이 뜨면 짜증나니까).
- **내 병에 별**: 서버가 각 병에 `is_mine`을 알려 주므로, 내 병 위에는 노란 별이 떠다녀요(`bottles3d.js`의 `makeStar`).
- **띄우기를 안전하게**: 서버까지 갔다 오는 데 시간이 걸리니, 그동안 버튼을 또 누르면 같은 병이 두 개 생길 수 있어요. 그래서 `placing` 깃발을 세우고 버튼을 잠급니다. 실패하면 이유를 보여주고 버튼을 "다시 띄우기"로 바꿔요. 쓴 내용은 그대로 남아 있습니다.
- **처음 한 번 옮기기**: A단계에서 폰에만 저장했던 병이 있으면 해변에 들어갈 때 서버로 올리고, 다 올라간 것은 폰 목록에서 지웁니다.
- **메시지 보기**: 내 병 목록도 서버(`store.mine()`)에서 받아 옵니다. 답글·좋아요 표시는 22번에서 더 다듬어요.

테스트는 진짜 서버 대신 가짜 Supabase(`tests/e2e/fake-supabase.mjs`)를 끼워서 돌립니다. 가짜가 진짜와 같은 규칙인지는 `fake-supabase.spec.mjs`가 따로 확인해요.
