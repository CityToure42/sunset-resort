# 05. 소품과 충돌 — 해변을 채우고, 부딪히게 하기

- `src/scene/props.js` — 야자수(휘어진 관 + 잎 8장 + 코코넛), 수상 방갈로(기둥·데크·벽·지붕·불 켜진 창·다리), 선베드 세트(침대·파라솔·사이드테이블·칵테일), 해변 바(카운터·기둥·지붕·칵테일 3잔)를 전부 상자·구·원기둥·원뿔 같은 기본 도형으로 조립합니다. 3D 모델 파일이 하나도 없는 이유입니다. 각 소품은 `{x, z, r}` 원 하나를 돌려줘서 "여기엔 못 들어간다"를 알려줍니다. `makeCocktail()`은 캐릭터 손에도 쓰이므로 밖으로 내보냅니다.
- `src/scene/world.js` — 하늘·바다·모래·소품을 한 번에 조립하는 `createWorld()`, 갈 수 있는 범위로 좌표를 자르는 `clampToBeach()`, 소품 원과 겹치면 밖으로 밀어내는 `resolveColliders()`. 캐릭터는 매 프레임 `world.clamp(위치)`를 거쳐서 바다 깊은 곳이나 야자수 속으로 못 들어갑니다. 수학은 단순합니다: 원 중심까지 거리가 (소품 반지름 + 캐릭터 반지름)보다 짧으면 그 방향으로 딱 그만큼 떨어뜨려 놓습니다.
- `scripts/link-three.mjs` — 브라우저는 importmap으로 `'three'`를 찾지만 Node는 모릅니다. 그래서 테스트 전에 `node_modules/three → vendor/three` 바로가기를 만들어 같은 복사본을 쓰게 합니다. 한 벌의 three.js로 브라우저와 테스트가 똑같이 돕니다.
