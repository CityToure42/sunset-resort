# 03. 날짜와 무드 — "지금 몇 시냐"를 앱이 아는 법

- `src/state/daily.js` — 폰 시계는 세계 어디서든 UTC(세계 표준시)로 시간을 세고, 우리는 한국시간(UTC+9)으로 "오늘"을 정해야 합니다. 그래서 `kstDateKey()`는 시간에 9시간을 더한 뒤 날짜를 읽습니다. 타임존 라이브러리 없이 이 한 줄로 끝납니다. `CocktailCounter`는 `{ date, count }`만 기억하고, 셀 때마다 "날짜가 바뀌었나?"를 먼저 확인해 바뀌었으면 0부터 다시 셉니다. 그래서 앱을 켜둔 채 자정을 넘겨도 맞습니다(테스트 "자정 경계"가 그걸 보장).
- `src/state/mood.js` — 하늘·바다·조명 색을 한 묶음(팔레트)으로 세 개 적어두고, `moodAt(시각)`이 "18:30~19:00은 골든아워, 19:00~19:30은 드라마틱, 나머지는 파스텔"을 돌려줍니다. 색 값은 목업에서 고른 그대로입니다. 나중에 "밤 하늘"을 추가하고 싶으면 팔레트 하나와 시간 조건 한 줄만 더하면 됩니다.

`class`가 처음이라면: `CocktailCounter`는 "값(date, count)과 그 값을 다루는 함수(take, remaining)를 한 상자에 담은 것"입니다. `#rollover`처럼 `#`이 붙은 함수는 상자 안에서만 쓰는 비공개 도우미입니다.
