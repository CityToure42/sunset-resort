# 16. 배포 — 내 폰에서 열리기까지

- 이 앱은 "빌드" 과정이 없는 정적 웹앱입니다. 폴더에 있는 파일이 그대로 웹에 올라가면 끝이라, GitHub Pages(무료 정적 호스팅)에 폴더를 올리기만 하면 `https://아이디.github.io/sunset-resort/` 주소가 생깁니다. 절차는 `docs/deploy.md`.
- **Claude 미리보기 링크** — GitHub 준비 전에 볼 수 있도록 Claude 아티팩트로도 올렸습니다. `scripts/build-artifact.mjs`가 `index.html`에서 문서 뼈대 태그(`<html>`, `<head>`, `<body>`)를 벗겨 `dist-artifact/`에 담는데, 아티팩트는 올릴 때 자기 뼈대를 씌우기 때문입니다. 단, 아티팩트는 보안 규칙이 엄격해서(외부 서버 접속 불가 등) B단계부터는 GitHub Pages가 필수입니다.
- 배포 후 확인은 `docs/checklist-phone.md`의 5가지. 자동 테스트는 컴퓨터 속 가짜 브라우저(그래픽 카드 없이 소프트웨어로 그림)에서 돌기 때문에, 실제 폰의 부드러움·터치 감각은 직접 봐야 합니다.
