# 08. 이동과 카메라 — 손가락과 키보드가 캐릭터가 되기까지

- `src/ui/joystick.js` — 폰용 가상 조이스틱. 투명한 층(`#joystick-layer`) 아무 곳이나 누르면 그 자리에 둥근 바탕과 손잡이가 생기고, 끄는 만큼 `vector {x, y}`(길이 최대 1)가 됩니다. 손을 떼거나(`pointerup`) 시스템이 터치를 끊으면(`pointercancel`) 즉시 0으로 돌아갑니다 — 그렇지 않으면 캐릭터가 혼자 계속 걷는 버그가 됩니다. 버튼 위에서 시작한 터치는 무시합니다.
- `src/ui/keyboard.js` — 방향키·WASD를 같은 모양의 `vector`로 바꿉니다. 조이스틱과 키보드가 같은 모양의 값을 내놓으니 플레이어 코드는 둘을 구분할 필요가 없습니다.
- `src/character/player.js` — `step(dt, input, camYaw)`가 핵심입니다. 입력의 "앞"은 화면 기준이라 카메라가 돌아 있으면 "앞"도 같이 돌아야 합니다. 그래서 카메라 각도(`camYaw`)로 앞/오른쪽 방향을 먼저 계산한 뒤 입력을 섞습니다. 속도는 초당 2.5, `dt`는 0.05초로 자릅니다(백그라운드에 있다가 돌아오면 dt가 수십 초가 되어 캐릭터가 순간이동하는 걸 막음). 새 위치는 `world.clamp`를 거쳐 범위·충돌을 지킵니다.
- `src/scene/camera.js` — 카메라 리그. `follow` 모드는 캐릭터 머리 위 지점을 기준으로 yaw(좌우)·pitch(위아래) 각도만큼 떨어진 곳에 카메라를 두고, 실제 위치는 목표 쪽으로 서서히(lerp) 따라갑니다. `zen` 모드는 지정 위치에 고정한 채 아주 느리게 좌우로 흔들리고, `fixed`는 고정만 합니다.
- `src/main.js` — 매 프레임: 입력 읽기 → `player.step` → `cameraRig.update` → 바다 출렁임 → 그리기. 터치 화면 오른쪽 절반 드래그와 마우스 드래그는 카메라 회전, 왼쪽 절반 터치는 조이스틱입니다.
