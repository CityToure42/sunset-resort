# 06. 캐릭터 — 도형 조립으로 사람 만들기

`src/character/avatar.js`의 `buildAvatar(look)`는 휴양객을 이렇게 조립합니다.

- 뼈대는 **그룹 안의 그룹**입니다. `group`(발바닥 기준) → `body`(몸통, 높이 0.98) → `head`(머리, 몸통 위 0.52). 팔은 `body`의 어깨에, 다리는 `group`의 허리에 붙습니다. 이렇게 하면 몸통을 돌릴 때 머리와 팔이 같이 돌고, 다리는 그대로 있습니다.
- 팔·다리는 `limb()`로 만듭니다. 그룹의 원점을 관절(어깨·허리)에 두고 원기둥을 그 아래로 늘어뜨려서, 그룹의 `rotation.x`만 바꾸면 관절을 축으로 앞뒤로 흔들립니다. 다음 작업(동작)이 바로 이 값을 움직입니다.
- 칵테일은 오른손(`armR`) 끝에 달려 있어 팔을 들면 같이 올라갑니다.
- `setLook(look)`은 네 가지만 합니다: 밀짚모자/버킷햇 그룹의 `visible`을 켜고 끄기, 선글라스 `visible`, 셔츠(`torso`) 재질의 색 바꾸기, 칵테일 액체(`liquid`라는 이름의 메쉬) 색 바꾸기. 새 메쉬를 만들지 않고 보이기/색만 바꾸니 가볍습니다.

테스트는 WebGL 없이 Node에서 돌아갑니다. three.js의 장면 그래프(그룹·메쉬·재질)는 그림을 그리지 않아도 만들 수 있어서, "모자가 숨겨졌나", "셔츠 색이 바뀌었나", "키가 1.6~1.9인가"를 숫자로 확인합니다.
