# 22. 메시지 보기 — 내 편지에 온 ♥와 답글, 그리고 빨간 점

"메시지 보기" 탭을 누르면 **내가 띄운 편지들**이 보여요. 각 편지에는 이런 게 붙어요.

- 모양 이름과 날짜, `♥ 좋아요 수 · 답글 수`
- 받은 답글 내용(최근 20개)
- 신고가 3번 모여 모두의 바다에서 숨겨졌다면 **"숨겨짐"** 태그
  (내 목록에서는 계속 보여요. 지우고 싶으면 관리자가 Supabase에서 지워요 → `docs/deploy.md`)

## 화면의 세 가지 상태: 불러오는 중 / 실패 / 결과

서버에 물어보는 화면은 항상 세 상태를 생각해야 해요.

1. **불러오는 중…** — 탭을 누르자마자 빈 화면 대신 이 글자를 먼저 보여줘요.
2. **실패** — "바다 소식을 불러오지 못했어요". 앱이 멈추지 않고 안내만 해요.
3. **결과** — 목록. 편지가 없으면 "아직 띄운 편지가 없어요".

코드는 `renderMessagesPanel(root, { bottles, loading, error, onClose })` 하나로 세 상태를 다 그려요(`src/ui/panels.js`).

## 빨간 점은 어떻게 켜고 끌까

"새 답글이 왔다"를 알려면 **내가 마지막으로 본 시각**을 기억해야 해요.

- 폰에 `profile.lastSeenReplyAt`(마지막으로 본 답글 시각)을 저장해요.
- 바다를 새로고침할 때마다(60초마다, 앱으로 돌아올 때) 내 편지들을 서버에 물어보고,
  **가장 최근 답글 시각 > 마지막으로 본 시각**이면 메시지 탭에 빨간 점을 붙여요(`hud.setUnread(true)`).
- 메시지 보기를 열면 "다 봤다"로 보고, 마지막으로 본 시각을 가장 최근 답글 시각으로 옮기고 점을 꺼요.
  폰에 저장하니까 새로고침해도 점이 다시 켜지지 않아요.

시각은 글자 그대로 비교하지 않고 `Date.parse`로 숫자로 바꿔서 비교해요.
서버가 주는 시각 글자의 모양이 조금 달라도(소수점 자리 등) 안전하게요.

## 이번에 같이 고친 것

- **답글 입력칸이 너무 좁았어요.** "보내기" 버튼이 `width: 100%` 스타일을 물려받아 입력칸을 밀어냈어요.
  360px 폭 테스트를 먼저 만들어 실패를 확인하고, 버튼 폭을 내용만큼으로 바꿨어요.
- **테스트가 진짜 서버로 나가던 문제.** 몇몇 A단계 테스트는 가짜 서버를 안 끼워서 진짜 Supabase로 요청을 보냈어요.
  테스트 컴퓨터는 거기 닿지 않아서 "바다 소식을 불러오지 못했어요" 토스트가 다른 안내를 덮었어요(가끔만 → 불안정한 테스트).
  이제 모든 테스트가 가짜 서버를 써요.
