# 33. 조개와 바 — 줍고, 사고, 마시기

친구 아이디어: "모히또 같은 건 처음부터 들고 있지 말고, 바를 따로 만들어서 거기서 사게 하자."

## 흐름
```
모래사장 조개(반짝) ──가까이 가면──▶ +1 🐚
석양멍 60초        ──────────────▶ +1 🐚
바 앞 "칵테일 사기" → 메뉴판 → 🐚3 → 손에 잔 → 놀기 "마시기" 3번 → 빈손
```

## 조개 놓기 (`src/scene/shells3d.js`)
- 모래사장(x −26~26, z −8~30) 중 **비어 있는 자리**에 12개를 놓아요. 비어 있다 = 수영장이 아니고, 야자수·바·선베드 같은 소품 둘레 밖(31번의 `isFreeSpot`).
- 캐릭터가 0.8m 안에 오면 주운 것으로 숨기고, **60초 뒤 다른 빈자리**에 다시 놓아요.
- 반짝임은 흐릿한 흰 원 그림(스프라이트)의 투명도를 사인 곡선으로 올렸다 내렸다 해요. 조개마다 박자를 다르게 해서 하나씩 반짝여요.
- 느린 폰에서 그래픽 품질이 낮아지면 반짝임을 꺼요.
- 조개는 각자 자기 화면에만 있어요(친구와 서로 뺏지 않아요).

## 메뉴판 (`src/ui/resortPanels.js`)
- 4가지 칵테일(색 동그라미 + 이름 + 🐚3). 이름은 지갑 규칙의 `MENU`, 색은 아바타의 `COCKTAIL_COLORS`를 그대로 써서, 메뉴판 색과 손에 든 잔 색이 늘 같아요.
- 조개가 모자라면 **누른 줄 바로 아래**에 "조개가 3개 필요해요".
- 이미 잔을 들고 있으면 "들고 있는 잔은 사라져요"를 미리 보여 줘요.

## 기능 묶음 (`src/features/resort.js`)
B단계의 `features/bottles.js`처럼, 리조트 놀거리는 이 파일에 모으고 app.js는 `setupResort(...)` 한 줄만 불러요.
- 잔이 바뀌면 `applyDrink()` 하나로 **아바타 잔·팔 자세·놀기 바의 "마시기" 버튼**을 한꺼번에 맞춰요. 셋을 따로따로 고치다 하나를 빼먹는 실수를 막아요.
- 잔·튜브가 바뀌면 `hooks.gear`를 불러요. 나중에(36번) 친구 화면에 알리는 데 써요.

## 없앤 것
"오늘의 칵테일 하루 5잔" 카운터(`CocktailCounter`)는 더 쓰지 않아서 코드와 테스트를 지웠어요.
안 쓰는 코드를 남겨 두면 나중에 읽는 사람이 "이건 어디서 쓰지?" 하고 헷갈려요. 날짜 계산 부분은 석양 무드에서 계속 써서 남겼어요.

## 화면 확인에서 고친 것
테스트는 다 통과했는데 스크린샷을 보니 메뉴판 버튼이 회색 상자에 글자만 붙어 있었어요(CSS를 안 줬기 때문).
색 동그라미·이름·가격이 한 줄에 정리되게 꾸몄고, 조개도 너무 작아서 1.7배로 키웠어요. **테스트 통과 ≠ 보기 좋음**이라 눈으로도 꼭 봐요.

## 최종 검토에서 고친 것
- **마지막 모금**: 예전엔 세 번째 "마시기"를 누르는 순간 잔이 사라져서, 빈손으로 마시는 동작을 했어요. 이제는 마시는 동작(1.5초)이 끝난 뒤에 빈손이 돼요. 그 1.5초 사이에 새 잔을 사면 '빈손 예약'을 취소해서 새 잔은 그대로 남아요(`setTimeout` + `clearTimeout`).
- **수영장·바다에서 바로 석양멍**: 물속에서 낮아진 몸 높이가 그대로 남아 선베드에 파묻혀 누웠어요. 석양멍을 시작할 때와 끝낼 때 몸 높이·헤엄 자세·걸음 속도를 모래 위 기본값으로 되돌려요.
- **친구 선베드 판정**: 내 화면의 친구는 받은 자리로 *미끄러져 가는 중*일 수 있어요. 그래서 "보이는 위치"가 아니라 "친구가 보낸 실제 자리(target)"로 빈 선베드를 판단해요.
