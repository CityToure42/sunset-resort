# 28. 말풍선 — 머리 위에 잠깐 뜨는 한마디

💬 버튼을 누르면 입력칸이 나와요. 30자까지 쓰고 "보내기"(또는 Enter)를 누르면
**내 캐릭터 머리 위**와 **해변에 있는 친구 화면의 내 캐릭터 머리 위**에 5초 동안 말풍선이 떠요.

## 저장하지 않는 채팅
말풍선은 서버에 저장하지 않고 **방송(Broadcast)** 으로만 보내요.
- 그 순간 해변에 있던 사람만 봐요. 나중에 들어온 사람은 못 봐요.
- 기록이 남지 않으니 지울 일도, 관리할 일도 없어요.

## 규칙
- 앞뒤 공백을 빼고 1~30자(입력칸 `maxlength="30"`, 받는 쪽도 30자에서 다시 자름)
- 2초에 한 번까지. 너무 빨리 또 보내면 아무 말 없이 입력칸에 그대로 남아요.
- 연결이 끊겨 있으면 "보내지 못했어요"가 뜨고 쓴 글은 남아요(다시 보내기 쉽게).
- 💬 버튼은 이동하기·놀기 모드에서만 보여요(석양멍·사진 중엔 숨김).

## 태그가 들어와도 안전한 이유
말풍선 글자는 `src/scene/labels.js`가 **캔버스에 그림으로 그려요**(`fillText`).
그래서 `<img src=x onerror=...>` 같은 글이 와도 그냥 그 글자 모양 그림이 될 뿐, 실행되지 않아요.
테스트에서 진짜로 그런 글을 보내 보고, 페이지에 `<img>`가 하나도 늘지 않았는지 확인해요.

## 만들다가 나온 버그 두 개
1. **내 말풍선이 안 사라짐.** 프레임마다 도는 함수 안에 "내 위치"를 `me`라는 이름으로 만들었는데,
   바깥에도 "내 말풍선"을 담은 `me`가 있었어요. 안쪽 이름이 바깥 것을 **가려서**(shadowing)
   말풍선 지우기 코드가 엉뚱한 걸 보고 있었어요. "5초 뒤 사라짐" 테스트가 잡아 줬고, 안쪽 이름을 `pos`로 바꿨어요.
2. **놀기 버튼이 안 눌림.** 채팅 영역의 빈 공간이 아래 놀기 버튼(인사·건배…)을 덮어서 눌러지지 않았어요.
   CSS 규칙끼리 힘겨루기에서 `#hud > *`(아이디 규칙)가 `.chat-box`(클래스 규칙)를 이겼기 때문이에요.
   CSS는 **아이디 > 클래스 > 태그** 순으로 셉니다. 그래서 `#hud > .chat-box`로 더 센 규칙을 써서 고쳤고,
   놀기 모드에선 💬 버튼을 동작 버튼 줄 위로 올렸어요. 기존 "건배가 보인다" 테스트가 이 버그를 잡아 줬어요.
