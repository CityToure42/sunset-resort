# 30. 조개 지갑 — 게임 속 "돈" 규칙 만들기

D단계에서는 칵테일을 **조개로 사요.** 돈 규칙은 실수하면 바로 티가 나요(조개가 두 번 빠지거나, 음수가 되거나).
그래서 화면과 상관없는 **순수 규칙 파일**(`src/state/wallet.js`)로 먼저 만들고 테스트했어요.

## 규칙
| 무엇 | 값 |
|---|---|
| 처음 조개 | 3개 (새 사용자·기존 사용자 모두) |
| 칵테일 한 잔 | 🐚3 |
| 한 잔 | 3모금(마시기 3번이면 빈손) |
| 조개 상한 | 9999 |
| 석양멍 보상 | 60초마다 +1 |

## 함수 세 개
- `earn(profile, n)` — 조개 늘리기(상한까지만)
- `buy(profile, 메뉴번호)` — 조개가 3개 이상이면 3개 빼고 잔을 들려 줘요. 모자라면 `{ ok: false, reason: 'shells' }`를 돌려주고 **한 개도 빼지 않아요.**
- `sip(profile)` — 한 모금. 남은 모금 수를 돌려주고, 0이 되면 빈손.

### "검사 먼저, 바꾸기는 나중"
`buy`는 먼저 메뉴 번호가 맞는지, 조개가 충분한지 **다 검사한 다음에** 조개를 빼요.
반대로 하면(빼고 나서 검사) 실패했을 때 되돌리는 코드를 따로 짜야 하고, 거기서 버그가 나기 쉬워요.

## 옛 프로필 정리
이미 앱을 쓰던 사람의 폰에는 조개 칸이 없어요. 앱이 열릴 때 `hydrateProfile`이
- 조개가 없거나 이상하면(음수, 소수, 10000) → 3
- 들고 있는 잔이 이상하면(없는 메뉴, 0모금) → 빈손
- 튜브가 목록에 없으면 → 없음
- 표정이 목록에 없으면 → 기본 미소
로 정리해요. 저장된 값은 언제든 깨져 있을 수 있다고 보고, 읽을 때마다 정리하는 게 안전해요.

## 왜 서버가 아니라 폰에?
친구들끼리 쓰는 앱이라 조개를 몰래 늘려도 큰일이 아니고, 서버 작업(SQL)을 줄일 수 있어서예요.
대신 폰마다 조개가 따로예요(새 폰에선 3개부터).
