# 10. 놀기·꾸미기·토스트 — 화면 위에 잠깐 뜨는 것들

- `src/ui/panels.js`
  - `showToast(문구, 시간)` — 화면 아래쪽에 잠깐 떴다 사라지는 알림. 이후 작업(칵테일 다 마심, 편지 띄움 등)이 전부 이걸 씁니다.
  - `renderPlayBar()` — 놀기 탭을 누르면 HUD 가운데 아래(`hud.middle`)에 인사·건배·춤·눕기·비치볼 버튼 5개가 생기고, 다른 탭으로 가면 사라집니다. 버튼은 "어떤 동작인지"만 알려주고(`onEmote('cheers')`), 실제로 무엇을 할지는 app.js가 정합니다.
  - `renderCustomizePanel()` — 아래에서 올라오는 시트. 진입 화면에서 쓰던 꾸미기 컨트롤(`renderLookControls`)을 그대로 재사용합니다. 하나 바꿀 때마다 캐릭터에 바로 반영되고 저장됩니다.
- `src/scene/effects.js` — 인사·건배 때 머리 위로 떠오르며 흐려지는 하트(캔버스로 그린 하트 그림을 스프라이트로), 비치볼(6조각 줄무늬 공이 포물선으로 날아가 바닥에 통통 튀다 1.2초 뒤 사라짐). 매 프레임 `effects.update(dt)`가 나이를 먹이고, 수명이 다하면 장면에서 지우고 메모리도 정리합니다(`dispose`). 이걸 안 하면 오래 놀수록 폰이 느려집니다.
- `src/app.js` — "모드가 바뀔 때" 훅에 놀기 바를 붙였다 떼는 코드, 동작 버튼을 눌렀을 때 애니메이션 + 이펙트를 함께 실행하는 `onEmote`를 추가했습니다.

이번에 겪은 함정: 테스트 도우미가 페이지를 열 때마다 저장소에 기본 프로필을 넣었더니, "새로고침 후에도 유지되나" 테스트에서 저장값을 덮어써 버렸습니다. 앱이 아니라 테스트의 잘못이었고, "비어 있을 때만 넣기"로 고쳤습니다.
