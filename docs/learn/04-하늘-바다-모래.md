# 04. 하늘·바다·모래 — 장면의 바탕

- `src/scene/sky.js` — 하늘은 반지름 300짜리 큰 공의 안쪽 면입니다(`side: BackSide`). 색은 작은 셰이더(GPU에서 도는 그림 공식)가 높이에 따라 지평선색→중간색→꼭대기색으로 섞어 칠합니다. 태양은 멀리(z −250) 놓은 원판이고, 그 위의 빛무리는 캔버스로 그린 둥근 그라데이션 그림(스프라이트)입니다. 조명은 세 개: 태양 방향 **주광**(그림자를 만듦), 얼굴을 밝히는 **보조광**, 하늘색과 모래색을 섞어 전체를 은은히 비추는 **환경광**. `applyMood(팔레트, blend)`는 이 모든 색을 한 번에 바꾸는데, `blend`를 0.05처럼 작게 주면 매 프레임 조금씩 섞여 서서히 변합니다.
- `src/scene/water.js` — 바다는 420×420 평면을 70×70 칸으로 쪼갠 것입니다. 매 프레임 각 꼭짓점의 높이를 사인파 세 개의 합으로 바꿔 출렁이게 합니다. 핵심은 `deep` 값: 해안선(z −9)에서 −22까지 파도 세기를 12%→100%로 키워서 모래 근처는 거의 평평합니다. 목업에서 바다가 모래 위로 비치던 문제의 해결책입니다. `setSegments(n)`은 나중에 폰이 느릴 때 칸 수를 줄이는 손잡이입니다.
- `src/scene/beach.js` — 모래는 납작한 판이 아니라 두께 0.6의 덩어리(`ExtrudeGeometry`)입니다. 해안선은 6단위마다 ±2.2씩 굽이치는 곡선이고, `rotateX(−90°)`로 눕힌 뒤 `translate`로 윗면을 높이 0에 맞춥니다. 젖은 모래 띠는 바다보다 살짝 높고(−0.04) 모래보다 낮아(0) 항상 바다 → 젖은 모래 → 모래 순서가 유지됩니다.

테스트는 화면 픽셀을 직접 읽습니다. 그려진 직후에만 읽을 수 있어서(`preserveDrawingBuffer`를 안 쓰면 화면에 보낸 뒤 버퍼가 비워짐) `samplePixel`은 읽기 전에 한 번 더 그립니다 — 이번 작업에서 실제로 부딪힌 함정이었습니다.
