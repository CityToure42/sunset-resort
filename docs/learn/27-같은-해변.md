# 27. 같은 해변 — 친구 캐릭터가 내 화면에 나타나기까지

`src/features/people.js`가 "다른 사람들"을 맡아요.

## 흐름 한눈에
```
친구 폰                                  내 폰
걷기 → 0.5초마다 위치(move) ──서버──▶  목표점 갱신 → 매 프레임 목표점 쪽으로 부드럽게
건배 → emote 'cheers'       ──서버──▶  친구 아바타가 건배 + 하트
꾸미기·모드 바뀜 → Presence  ──서버──▶  모자·셔츠 바꿔 그리기, 석양멍이면 누운 자세
```

## 일회용 번호(sid)
앱을 열 때마다 `crypto.randomUUID()`로 새 번호를 만들어요. 실시간에서는 이 번호로만 "누구"를 구분해요.
폰에 저장된 기기 열쇠(편지함 열쇠)는 절대 쓰지 않아요. 테스트로 보낸 메시지 전체에 열쇠가 없는지 확인해요.

## 부드럽게 따라가기 (보간)
위치는 0.5초에 한 번만 오니까, 그대로 옮기면 캐릭터가 순간이동하듯 뚝뚝 끊겨요.
그래서 매 프레임 **남은 거리의 일부만큼** 다가가게 했어요(`stepToward`).
`k = 1 - e^(-dt × 4.62)` — 0.5초면 남은 거리의 90% 넘게 따라잡아요.
(계획엔 4.6이었는데 계산해 보니 89.97%라 테스트 기준 90%에 살짝 못 미쳐서 4.62로 고쳤어요. 숫자는 꼭 확인!)

## 30초 정리와 가까운 30명
- 1초마다 "30초 동안 아무 소식 없는 사람"을 지워요. 가만히 서 있는 사람은 10초마다 `here`를 보내니까 지워지지 않아요.
- 사람이 30명보다 많으면 나와 가까운 30명만 그려요(먼 사람은 숨김). 폰이 버거워하지 않게요.

## 앱을 내렸다 올리면
화면이 숨겨지면 바로 채널에서 나가고, 다시 보이면 **같은 sid로** 들어와요.
그래서 친구 화면에서 내 캐릭터는 잠깐 사라졌다가 하나만 다시 나타나요(둘로 보이지 않음).

## app.js와 이어 붙이기 — "훅"
app.js는 다른 사람 사정을 몰라요. 대신 끼어들 자리(훅)를 열어 뒀어요.
- `hooks.emote` — 내가 동작하면(놀기·칵테일 마시기) 실시간으로 알림
- `hooks.look` — 꾸미기를 바꾸면 알림
- `hooks.mode` — 모드가 바뀌면(석양멍 등) 알림
people.js가 이 자리에 함수를 걸어 두는 방식이라 app.js는 한 줄(`setupPeople(...)`)만 늘었어요.

## 닉네임표
`src/scene/labels.js`가 캔버스에 글자를 그려서 3D 스프라이트(항상 카메라를 보는 그림)로 만들어요.
글자가 "그림"이 되니까 누가 `<b>` 같은 걸 이름에 넣어도 태그로 동작하지 않아요(애초에 닉네임 규칙에서 "손님"으로 바뀌기도 해요).

## 테스트: 창 두 개
`tests/e2e/two.mjs`가 한 브라우저에 페이지 두 개(하나·둘)를 열고 가짜 연결로 이어요.
- 서로 보이는지, 걸으면 따라오는지, 건배·꾸미기·석양멍이 보이는지
- 숨겼다 돌아와도 하나인지, 이상한 메시지(NaN·999·'explode')를 무시하는지
- 30초 정리, 기기 열쇠가 안 나가는지
"따라온다" 테스트는 처음에 "1초에 1m 넘게"로 썼다가, 테스트 컴퓨터가 느려 0.5m밖에 못 걸어서 실패했어요.
**걸은 거리와 상관없이 친구 화면의 내가 진짜 나와 같은 자리로 오는지**로 바꿨어요. 일부러 위치 받기를 끊어 보니 제대로 실패했어요.
