# 36. 친구도 보이게 — 실시간에 칸 두 개 더하기

D단계에서 만든 것(표정·잔·튜브·수영장)이 친구 화면에도 보여야 같이 노는 맛이 나요.
C단계에서 만든 실시간 구조 덕분에 바꿀 게 아주 적었어요.

## 보내는 것: 접속 상태에 두 칸
| 칸 | 값 | 언제 바뀌나 |
|---|---|---|
| `look.face` | 표정(원래 있던 look 안) | 꾸미기에서 표정 바꿀 때 |
| `tube` | 'donut'·'flamingo'·'watermelon' 또는 null | 튜브 빌리기·반납 |
| `drink` | 0~3(잔 색) 또는 null | 잔 사기·다 마시기 |

- 바뀔 때만 보내요(33번의 `hooks.gear`가 신호). 걸을 때마다 보내는 위치와 달리 거의 안 늘어요.
- 모금 수는 안 보내요. 친구 화면엔 "무슨 색 잔을 들었나"만 필요하니까요. **필요한 것만 보내기**가 사용량도 줄이고 정보도 덜 새요.

## 보내지 않는 것: "수영장에 있다", "바다에 떠 있다"
이건 위치(x, z)만 있으면 각자 폰에서 계산할 수 있어요(31번 `placeOf`).
친구 위치를 받으면 → 장소 계산 → 34번 `poseFor`로 자세(잠김·둥실·팔 젓기). **내 캐릭터와 똑같은 함수**를 써서 두 화면이 어긋나지 않아요.

## 받은 위치 범위 넓히기
C단계에서는 받은 위치를 해변 범위(z −12까지)로 당겼어요. 그러면 튜브 타고 z −20에 떠 있는 친구가 내 화면에선 해안에 붙어 보여요!
그래서 받는 쪽 범위를 **튜브 앞바다 끝(z −22)** 까지 넓혔어요. 설계할 때 미리 적어 둔 덕에 빠뜨리지 않았어요.

## 이상한 값은 기본값
누가 `tube: 'boat'`, `drink: 9`, 표정 `'evil'`을 보내도
- 튜브 → 없음, 잔 → 빈손, 표정 → 기본 미소
로 바꿔요(25번의 "믿지 않고 검사하기" 그대로). 아바타 쪽도 모르는 튜브 이름은 그리지 않아서 두 겹으로 막혀 있어요.

## 옛 버전 친구와 섞이면?
아직 새로고침 안 한 친구(C단계 버전)는 새 칸을 모르니 그냥 무시하고, 새 버전은 없는 칸을 "없음/빈손"으로 봐요. 서로 깨지지 않아요.
