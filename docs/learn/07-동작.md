# 07. 동작 — 상태 기계와 보간

`src/character/animations.js`의 `AnimationController`는 두 가지 일을 합니다.

1. **상태 기계**: 캐릭터는 항상 `idle`(가만히), `walk`(걷기), 또는 동작 하나(`wave`, `cheers`, `dance`, `lie`, `throw`, `drink`) 중 한 상태에 있습니다. `setMoving(true)`면 걷기로, `play('wave')`면 인사로 바뀌고, 각 동작은 `EMOTES`에 적힌 시간(인사 1.6초 등)이 지나면 저절로 `idle`로 돌아옵니다. `lie`(눕기)만 무한대라 `stop()`을 불러야 일어납니다. 동작 중에 움직이면 동작은 끊기고 걷기가 됩니다 — 사용자 입력이 항상 우선입니다.
2. **보간(lerp)**: 매 프레임 "목표 각도"를 정하고, 현재 각도를 목표 쪽으로 조금씩(`k = dt×10`만큼) 옮깁니다. 그래서 걷다가 멈춰도 다리가 뚝 끊기지 않고 자연스럽게 제자리로 돌아옵니다. 걷기는 `sin(시간 × 주파수)`로 왼다리·오른다리를 반대 위상으로 흔들고, 춤은 몸통을 좌우로 돌리며, 눕기는 몸 전체(`group`)를 뒤로 눕힙니다.

이 파일은 three.js의 `rotation.x` 같은 숫자만 바꾸므로 그래픽을 몰라도 읽을 수 있고, Node 테스트로 "1.7초 뒤 idle인가"처럼 시간에 대한 약속을 검사합니다.
