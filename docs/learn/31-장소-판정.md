# 31. 장소 판정 — "지금 어디에 서 있지?"

D단계에선 서 있는 곳에 따라 캐릭터가 달라져요. 모래에선 걷고, 수영장에선 가슴까지 잠기고, 튜브가 있으면 바다에 떠요.
그래서 위치(x, z)만 넣으면 장소를 알려 주는 규칙을 `src/scene/places.js`에 따로 만들었어요.

## 장소 네 가지 (`placeOf`)
```
        z = 40  ─────────── 해변 뒤쪽 끝
   모래(sand)       [수영장 pool: x 5~13, z 11.5~16.5]
        z = -9.5 ────────── 해안선
   얕은 물(shallow)  ← 튜브 없이 갈 수 있는 곳(발목 깊이)
        z = -12  ──────────
   바다(sea)        ← 튜브가 있어야 갈 수 있음
        z = -22  ────────── 튜브 끝(유리병 떠 있는 앞바다)
```
경계값(정확히 -9.5, -12인 곳)은 테스트에서 하나하나 확인했어요. 경계는 버그가 가장 잘 숨는 곳이에요.

## 튜브가 있으면 범위가 넓어진다 (`clampFor`)
캐릭터가 갈 수 없는 곳으로 가려고 하면 갈 수 있는 끝으로 "당겨" 놓아요(clamp).
- 튜브 없음: z는 -12까지
- 튜브 있음: z는 -22까지, 바다에선 x가 -28~28

`world.setReach({ tube: true })`를 부르면 그 뒤로 이 넓은 범위를 써요(튜브를 빌릴 때, 34번 문서).

## 빈 선베드 고르기 (`chooseSunbed`)
1. 선베드 6개를 나와 가까운 순서로 줄 세워요.
2. 석양멍 중인 친구에게서 1.5m 안에 있는 선베드는 빼요(찬 자리).
3. 남은 것 중 첫 번째! 다 찼으면 그냥 가장 가까운 자리.

## 선베드 자리 정하기
선베드 6개의 좌표는 숫자로 정했어요: (5.3, 2.0), (1.8, 2.0), (-1.7, 2.6), (8.7, 1.0), (3.5, 6.5), (7.5, 6.5).
"서로 3m, 야자수와 2m, 바와 3.5m 넘게 떨어지고 수영장과 안 겹친다"를 테스트로 만들어서, 나중에 누가 좌표를 바꿔도 겹치면 바로 알 수 있어요.

## 고친 구조 두 가지
- **순환 참조 피하기**: `places.js`가 `world.js`의 범위(BOUNDS)를 쓰고, `world.js`도 `places.js`를 쓰면 서로가 서로를 불러요.
  그래서 BOUNDS를 `places.js`로 옮기고 `world.js`는 그대로 다시 내보내게 했어요.
- **테스트하기 쉽게 나누기**: 해변 전체(`createWorld`)는 하늘 그림을 그리느라 브라우저가 있어야 해서 Node 테스트에서 못 만들어요.
  그래서 "충돌 + 범위" 부분만 `createClamp`로 떼어 내서 따로 테스트했어요.
- 이동 속도는 `player.speed`를 바꾸면 바로 반영돼요(물속에선 느리게, 35번 문서).
