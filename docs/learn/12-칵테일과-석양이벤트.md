# 12. 오늘의 칵테일과 석양 이벤트 — 시간이 흐르는 해변

- **오늘의 칵테일**: 캐릭터가 해변 바에서 2.6 거리 안에 들어오면 화면 가운데 아래에 "칵테일 받기" 버튼이 나타납니다(매 프레임 거리 계산). 누르면 `CocktailCounter.take()`가 하루 5잔 규칙을 지키며 세고, 성공하면 마시는 동작, 다 마셨으면 "오늘 칵테일은 다 마셨어요. 내일 또 만나요". 횟수와 날짜는 프로필에 저장돼 앱을 껐다 켜도 유지됩니다.
- **1초마다 시계 확인**(`checkClock`): 자정이 지났으면 배지를 0/5로 돌리고, `moodAt(지금)`으로 하늘 분위기를 정합니다. 분위기가 드라마틱으로 바뀌는 순간 "석양 이벤트가 시작됐어요" 알림이 뜨고 배지가 "석양 이벤트 진행 중"으로 바뀝니다. 계획엔 10초마다였는데, 자정 초기화가 바로 보이도록 1초로 했습니다(계산이 아주 가벼워서 부담 없음).
- **서서히 바뀌는 하늘**: 매 프레임 `sky.applyMood(목표, 작은 비율)`을 불러 현재 색을 목표 색 쪽으로 조금씩 섞습니다. 그래서 18:30에 골든아워로, 19:00에 드라마틱으로 1~2초에 걸쳐 부드럽게 넘어갑니다.
- **테스트용 시계**: 저녁 7시를 기다릴 수는 없으니, 테스트는 `__app.setNow(...)`로 시계를 바꿔 끼웁니다. 또 테스트를 실제로 몇 시에 돌리든 결과가 같도록, 테스트 페이지에는 `window.__SR_NOW__`로 "오후 3시"를 고정해 둡니다. 실제 사용자 폰에는 이 값이 없으므로 항상 진짜 현재 시각을 씁니다.
