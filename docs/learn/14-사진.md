# 14. 사진찍기 — 3D 화면을 이미지로

- `captureFrame()` (`src/scene/renderer.js`) — WebGL 캔버스는 화면에 보낸 뒤 내용이 지워지는 게 기본입니다(성능 때문에). 그래서 "지금 한 번 그리고 → 같은 순간에 2D 캔버스로 복사"합니다. 2D 캔버스로 옮기면 그 위에 글씨를 쓰거나 PNG로 바꿀 수 있습니다. 버튼·배지 같은 HTML UI는 3D 캔버스에 없으니 사진에 안 찍혀서, 해변 장면만 깔끔하게 남습니다.
- `src/ui/photo.js`
  - `drawWatermark()` — 왼쪽 아래에 반투명 어두운 알약을 깔고 흰 글씨로 "Sunset Resort · 닉네임"을 씁니다. 하늘이 밝든 어둡든 읽히게 하려고 배경 알약을 둡니다. 글씨 크기는 사진 해상도에 비례합니다.
  - `takePhoto()` — 캡처 → 워터마크 → `toBlob`으로 PNG 파일 데이터.
  - `sharePhoto()` — 폰이 파일 공유를 지원하면 공유 시트(카톡·인스타·사진 저장 등)를, 아니면(PC 등) 다운로드를 띄웁니다. 공유 시트에서 사용자가 취소하면 아무 일도 하지 않습니다.
- `src/app.js` — "사진찍기"는 머무는 모드가 아니라, 탭을 누르면 찰칵(화면이 잠깐 하얗게 번쩍) 찍고 바로 원래 모드(이동하기 또는 놀기)로 돌아갑니다. 연속으로 눌러도 한 장씩만 처리되게 `photoBusy`로 막습니다.
