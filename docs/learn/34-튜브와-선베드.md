# 34. 튜브와 선베드 — 장소에 따라 달라지는 캐릭터

## 선베드 6세트
- 선베드+파라솔을 6세트로 늘렸어요(좌표는 31번 문서). 같은 함수 `sunbedSet`을 6번 부르면 끝 — 함수로 만들어 두면 늘리기 쉬워요.
- "석양멍하기"를 누르면 `chooseSunbed`로 **가장 가까운 빈 선베드**를 골라요.
  빈 자리 판단에는 같은 해변의 친구 중 석양멍 중(mode zen)인 사람의 위치를 써요(C단계 실시간 정보 재사용).
- 테스트: 친구(A)가 (1.8, 2.0)에 누운 뒤 내가(B) 같은 곳에서 석양멍을 누르면 다음으로 가까운 (3.5, 6.5)에 누워요.

## 튜브 대여소
- 바닷가(−12, −7)에 나무 거치대와 튜브 3개를 만들었어요.
- 거치대 2.6m 안 **모래 위**에서만 "튜브 빌리기"/"튜브 반납" 버튼이 떠요. 바다에 떠 있을 땐 반납 버튼이 없어요(물 위에서 튜브를 놓으면 이상하니까).
- 빌리면: 허리에 튜브(`setTube`) + 갈 수 있는 범위를 앞바다까지(`world.setReach({ tube: true })`) + 폰에 저장.

## 서 있는 곳에 맞는 자세 (`poseFor`)
매 프레임 "지금 어디?"(31번 `placeOf`)를 보고 자세를 정해요.
| 장소 | 몸 높이(baseY) | 팔 | 속도 |
|---|---|---|---|
| 모래 | 0 | 보통 | 2.5 |
| 튜브 + 물(얕은 물·바다) | −0.55 ± 0.06 둥실 | 보통 | 0.7배 |
| 수영장 | −0.9 | 팔 젓기 | 0.6배(35번) |

- 높이는 목표값으로 **조금씩** 다가가게 했어요(`baseY += (목표 − 지금) × 비율`). 장소가 바뀌는 순간 몸이 툭 꺼지지 않아요.
- 이 규칙(`poseFor`)은 함수로 따로 내보내서, 친구 캐릭터도 똑같은 규칙으로 그려요(36번).

## 첫 안내
튜브 없이 바다로 걸어가 끝(z −12)에 닿으면 "튜브를 빌리면 더 나갈 수 있어요"를 **한 번만** 띄워요. 매번 뜨면 귀찮으니까요.
