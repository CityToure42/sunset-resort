# 02. 저장과 닉네임 — 화면 없이도 돌아가는 "순수 로직"

이번 파일들은 3D도, 버튼도 없습니다. 그래서 브라우저 없이 Node에서 바로 테스트할 수 있고, 가장 빨리 고칠 수 있는 부류의 코드입니다.

- `src/state/storage.js` — 폰 브라우저의 `localStorage`에 앱 상태를 JSON 문자열로 저장합니다. 키는 `sunset-resort:v1` 하나뿐이라 저장된 모든 것이 그 한 줄에 들어 있습니다. 저장소가 막혀 있거나(사파리 비공개 모드) 저장된 글자가 깨져 있으면 앱이 죽지 않도록 빈 객체로 시작하고, `isPersistent`를 `false`로 바꿔서 나중에 "이번엔 저장이 안 돼요"를 띄울 근거를 남깁니다.
- `src/state/nickname.js` — `suggestNickname()`은 형용사 목록과 명사 목록에서 하나씩 뽑아 "나른한 코코넛"처럼 만듭니다. `validateNickname()`은 공백을 다듬고 2~10자, 한글·영문·숫자만 허용합니다. 실패 이유를 `'length'`/`'chars'`로 돌려줘서 화면이 알맞은 문구를 고를 수 있게 합니다.
- `src/state/profile.js` — "내 정보"의 기본 모양입니다. `token`은 회원가입 대신 쓰는 비밀 열쇠(UUID)이고, `look`은 꾸미기 값입니다. `normalizeLook()`은 저장된 값이 이상해도(예: 셔츠 9번) 기본값으로 돌려놓고, `hydrateProfile()`은 저장된 내용과 기본값을 합쳐 항상 완전한 프로필을 만듭니다.

테스트(`tests/unit/*.test.js`)는 Node 내장 러너로 돌립니다: `npm run test:unit`. 각 테스트 이름이 곧 "이 함수가 지켜야 할 약속"입니다.
