# 35. 버블풀 — 수영장과 비눗방울

친구 아이디어: "리조트에서 버블풀파티를 해야 할 것 같고, 수영장이 필요해."
해변 뒤쪽 오른쪽(가운데 (9, 14), 8×5m)에 **항상 열린 버블풀**을 만들었어요(`src/scene/pool.js`).

## 만드는 법
- **물**: 밝은 청록색 반투명 판 하나. 모래 윗면 바로 위(높이 0.05)에 깔았어요.
- **테두리**: 흰 상자 네 개, **사다리**: 반원 손잡이 두 개.
- **물속처럼 보이는 비밀**: 수영장에 들어가면 캐릭터 몸을 0.9 내려요. 모래는 두꺼운 덩어리라 모래 아래로 내려간 다리·허리를 가려 주고,
  위에서 보면 가슴까지 물에 잠긴 것처럼 보여요. 진짜 구멍을 파지 않고 **보이는 것만** 그럴듯하게 만든 거예요(게임에서 흔한 방법).
  계획엔 물 높이를 −0.25로 적었는데, 그러면 물이 모래에 덮여 안 보여서 0.05로 바꿨어요.

## 비눗방울
- 반투명 구 40개. 각자 시작 자리·떠오르는 높이(1.5~3m)·속도가 달라요.
- 시간 t로 위치를 계산해요: `k = (t × 속도 + 시작값) % 1` → 0에서 1까지 갔다가 다시 0. k만큼 떠오르고, 꼭대기(0.92 넘으면)에서 작아지며 "톡" 사라져요.
  상태를 따로 저장하지 않고 **시간만으로** 계산하니 코드가 짧고 버그가 적어요.
- 수면엔 흰 원판 30개(거품)가 살짝살짝 출렁여요.
- 느린 폰(그래픽 품질 low)에선 비눗방울을 20개만 띄워요.

## 들어가면
34번의 자세 규칙(`poseFor`)대로 가슴까지 잠기고(높이 −0.9), 걸으면 다리 대신 팔을 저어요, 속도는 0.6배.
수영장 안에서도 놀기 동작·말풍선은 그대로예요.

## 테스트에서 배운 것
- "들어가면 잠긴다"를 "1.2초 기다린 뒤 높이 확인"으로 썼더니, 느린 테스트 컴퓨터에서 가끔 실패했어요(프레임이 적어 덜 내려감).
  **정해진 시간만큼 기다리기** 대신 **될 때까지 기다리기**(최대 4초)로 바꿨어요.
- "경계에서 높이가 튀지 않는다"는 매 프레임 높이를 기록해서 한 프레임 변화가 0.3보다 작은지 봐요.
  일부러 "서서히 바꾸기"를 빼 보니 한 프레임에 0.45 뚝 떨어져 테스트가 실패했어요 — 테스트가 진짜 지키고 있어요.
