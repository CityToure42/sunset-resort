# 15. 품질 자동 조정과 오류에 버티기

- **자동 품질 조정** (`src/state/quality.js` + app.js) — 앱이 뜬 뒤 처음 3초(또는 180프레임) 동안 매 프레임 걸린 시간을 모아 평균 fps를 냅니다. 30fps보다 느리면 한 번만 "그래픽 낮추기"를 합니다: 태양 그림자 끄기, 바다 칸 수 70→35(계산량이 약 4분의 1). 그리고 "부드럽게 보이도록 그래픽을 낮췄어요"라고 알려 줍니다. 0.5초보다 긴 프레임(다른 앱 갔다 오기 등)은 측정에서 뺍니다. 주의할 점: 캐릭터 이동에 쓰는 시간은 0.05초로 자르지만, 측정에는 자르기 전 "진짜" 시간을 써야 느린 폰을 제대로 알아챕니다.
- **저장이 안 될 때** — 사파리 비공개 모드나 저장 공간이 꽉 찬 경우, 읽기는 되는데 쓰기만 실패하기도 합니다. 그래서 저장소를 열 때 작은 값을 한 번 써 보고(probe) 지워서, 쓰기가 막혔는지 미리 압니다. 막혔으면 앱은 그대로 동작하되(메모리에만 기억) 해변에 들어가자마자 "이번엔 저장이 안 돼요"라고 알려줍니다. 앱을 닫으면 그날의 기록은 사라진다는 뜻입니다.
- **테스트용 스위치** — 테스트 컴퓨터는 그래픽 카드 없이 소프트웨어로 그려서 느립니다. 그대로 두면 모든 테스트에서 "그래픽을 낮췄어요" 알림이 떠서 다른 알림 검사를 방해하므로, 테스트에서는 `window.__SR_QUALITY__ = 'high'`로 자동 조정을 꺼 둡니다(실제 폰에는 이 값이 없음).
- `docs/checklist-phone.md` — 폰에서 직접 확인할 5가지. 자동 테스트로는 "손맛"과 실제 폰 성능을 볼 수 없어서 이 부분은 사람이 봐야 합니다.
