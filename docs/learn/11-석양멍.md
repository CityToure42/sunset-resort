# 11. 석양멍 — 이 앱의 메인 장면

석양멍 탭을 누르면 `src/app.js`의 `enterZen()`이 순서대로 이렇게 합니다.

1. 캐릭터를 선베드로 순간이동(`player.teleport`)하고 눕기(`anim.play('lie')`).
2. 카메라를 선베드 왼쪽 뒤, 조금 높은 곳에 고정(`cameraRig.setZen`)하고 바다 쪽을 내려다보게 합니다. 카메라는 아주 느리게(약 25초 주기) 좌우로 흔들려서 "멍 때리는" 느낌을 냅니다.
3. HUD를 숨기고 석양멍 화면(`src/ui/zen.js`)을 띄웁니다: 문구 한 줄, 경과 시간, 파도 소리 버튼, 끝내기 버튼.
4. 1초마다 이번 석양멍 시간과 누적 시간(`profile.zenSeconds`)을 하나씩 올리고 저장합니다. 화면 표시는 `formatZen()`이 "잠시 → 3분째 → 1시간 12분째"로 바꿔 줍니다.

끝내기를 누르면 `exitZen()`이 반대로: 타이머·소리 정지, 캐릭터를 선베드 앞(바다 쪽)으로 세우고, 카메라를 다시 따라가기 모드로, HUD 복귀.

- `src/audio/waves.js` — 소리 파일 없이 파도 소리를 **합성**합니다. 무작위 소음을 "핑크 노이즈"(낮은음이 더 큰 쏴아 소리)로 만들고, 900Hz 위를 깎아(로우패스) 부드럽게 한 뒤, 7초 주기로 볼륨을 올렸다 내려서(LFO) 파도가 밀려왔다 빠지는 느낌을 냅니다. 브라우저는 사용자가 버튼을 누르기 전엔 소리를 못 내게 막아 두기 때문에, 기본은 꺼짐이고 버튼으로 켭니다.

이번에 고친 것 두 가지: (1) 캐릭터 몸의 회전 순서를 `'YXZ'`로 바꿨습니다. 예전엔 "뒤로 젖히기"가 세계 기준이라 바라보는 방향에 따라 엎드리는 문제가 있었는데, 이제는 어느 쪽을 보든 등을 대고 눕습니다. (2) 선베드를 등받이가 바다 반대편에 오도록 돌리고 파라솔을 옆으로 비켜, 누우면 발끝 너머로 석양이 보이게 했습니다. 스크린샷을 여러 번 찍어 보며 카메라 위치를 맞췄습니다.
