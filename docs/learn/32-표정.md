# 32. 표정 — 도형 몇 개로 얼굴 만들기

친구(지현)가 "선글라스 벗으면 표정을 고를 수 있으면 좋겠다"고 해서 표정 6가지를 만들었어요.
모두 **기본 도형**(구·도넛·상자·평면 모양)으로 그렸어요. 그림 파일이 없어서 앱이 가볍고, 색·크기를 코드로 바로 바꿀 수 있어요.

| 표정 | 눈 | 입 |
|---|---|---|
| 기본 미소 | 작은 검은 점 둘 | 아래로 휜 반원(도넛의 반쪽) |
| 땡그란 눈 | 흰 구 + 검은 눈동자 | 작은 동그라미 |
| 활짝 웃음 | ∩ 모양(도넛 반쪽) | 크게 벌린 반원(어두운 빨강) |
| 윙크 | 점 하나 + 가로선 하나 | 반원 |
| 하트 눈 | 빨간 하트(곡선으로 그린 모양) | 반원 |
| 졸린 눈 | 살짝 기운 가로선 둘 | 짧은 가로선 |

## 눈과 입을 따로 묶은 이유
표정 하나 = "눈 그룹(eyes)" + "입 그룹(mouth)". 선글라스를 쓰면 **눈 그룹만 숨겨요.**
선글라스 뒤에 눈이 겹쳐 그려지면 이상하게 비칠 수 있거든요. 입은 그대로 보여서, 선글라스를 써도 웃는지·놀랐는지는 보여요.

## 이름으로 꺼내 쓰기
`avatar.parts.faces`는 3D 그룹이면서 `faces.heart`, `faces.wink`처럼 이름으로도 꺼낼 수 있게 했어요.
`setLook({ face: 'heart' })`를 부르면 하트 눈만 보이고 나머지 다섯은 숨겨져요.

## 빈손과 튜브도 준비
- `setDrink(번호)` / `setDrink(null)` — 손에 든 잔 보이기/숨기기. 이제 처음엔 **빈손**이에요(33번에서 바에서 사요).
- 빈손일 때 오른팔이 잔 든 자세로 떠 있으면 어색해서, 동작 담당(`AnimationController`)에 `holding`을 만들어 빈손이면 팔을 내려요.
- `setTube('flamingo')` — 허리에 튜브(도넛·플라밍고·수박). 34번에서 빌려요.
- `baseY`(몸 높이)·`swim`(팔 젓기) — 수영장·튜브에서 쓸 자세(35번).

## 꾸미기
꾸미기의 "칵테일" 줄을 "표정" 줄로 바꿨어요. 표정은 다른 꾸미기처럼 폰에 저장되고, 새로고침해도 남아요.

## 눈으로 확인하기
테스트는 "하트 눈이 보이는 상태인가(visible)"까지만 알 수 있어요. 진짜로 예쁜지는 사람 눈이 필요해서,
6가지 표정(선글라스 벗음/씀)과 튜브 3종을 가까이서 찍어 한 장에 모아 직접 확인했어요.
