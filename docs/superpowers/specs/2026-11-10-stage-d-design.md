# Sunset Resort D단계 — 리조트 놀거리 (설계 문서)

작성일: 2026-11-10 · 상태: 사용자 검토 대기 · 선행: `2026-11-10-stage-c-design.md`(C단계 완료·배포, 두 폰 확인 완료)
출처: 친구(지현) 의견 카톡 → 이세민 님과 대화로 확정(2026-11-10)

## 1. 목표와 범위

친구들과 같이 놀 거리를 늘린다. 5가지를 한 번에(사용자 결정):
1. 조개를 모아 바에서 칵테일 사기(처음엔 빈손)
2. 표정 고르기(6가지)
3. 비치 의자(선베드+파라솔) 6세트, 석양멍은 가까운 빈 자리
4. 튜브 대여소 → 튜브 타고 앞바다 떠다니기
5. 항상 열린 버블풀(수영장 + 비눗방울·거품)

모두 C단계 실시간으로 친구 화면에도 보인다.
범위 밖:
- 조개 서버 저장·기기 간 동기화
- 선물하기
- 수영장 음악·조명 파티 시간
- 튜브 충돌
- 효과음
- 마신 뒤 화면 효과
- 새 칵테일 종류

## 2. 화면 동작

### 2.1 조개와 바
- **시작:**
  - 새 사용자와 기존 사용자 모두 조개 3개, 빈손으로 시작한다.
  - 꾸미기의 "칵테일" 고르기는 없앤다.
- **조개 줍기:**
  - 모래사장(z −8 ~ 30, 소품 충돌 피함)에 반짝이는 조개 12개를 둔다.
  - 캐릭터가 0.8m 안에 오면 자동으로 줍는다(토스트 "+1 🐚").
  - 주운 조개는 60초 뒤 다른 무작위 자리에 다시 생긴다.
  - 조개는 각자 자기 화면에만 있다(친구와 공유하지 않음).
- **석양멍 보상:** 석양멍 60초마다 조개 1개.
- **배지:** "오늘의 칵테일 n/5"를 "🐚 n"으로 바꾼다. 하루 5잔 제한은 없앤다(기존 카운터는 더 쓰지 않는다).
- **바:**
  - 바(−5.5, 4) 근처에서 기존 "칵테일 받기" 자리에 "칵테일 사기" 버튼이 뜬다.
  - 누르면 메뉴판 시트가 뜬다. 메뉴 4종은 지금의 칵테일 색 4개를 그대로 쓴다: 선셋 오렌지·블루 라군·핑크 플라밍고·모히또, 각 🐚3.
  - 조개가 모자라면 그 버튼에 "조개가 3개 필요해요"를 띄우고 조개를 줄이지 않는다.
  - 이미 들고 있으면 메뉴판에 "들고 있는 잔은 사라져요"를 적고, 사면 새 잔으로 바꾼다.
- **마시기:**
  - 산 잔은 손에 든다. 남은 모금은 3이다.
  - 놀기 바에 "마시기" 버튼이 생긴다(잔이 있을 때만). 누르면 마시기 동작을 하고 모금이 1 줄어든다. 0이 되면 잔이 사라진다.

### 2.2 표정
- 꾸미기에 "표정"이 생긴다. 종류는 기본 미소(smile)·땡그란 눈(round)·활짝 웃음(grin)·윙크(wink)·하트 눈(heart)·졸린 눈(sleepy).
- 선글라스를 쓰면 눈이 가려지고 입만 보인다.
- 표정은 친구 화면에도 보인다.

### 2.3 비치 의자
- 선베드+파라솔은 6세트로 한다. 기존 자리(5.3, 2.0)는 유지한다. 나머지는 해변 앞쪽에 바다를 향해 나란히 두고, 야자수·바와 겹치지 않게 한다(좌표는 계획에서 정한다).
- "석양멍하기"를 누르면 내 위치에서 가장 가까운 **빈** 선베드에 눕는다.
  - 빈 자리는 석양멍 중인 친구(Presence mode zen)의 위치로부터 1.5m 안에 있지 않은 선베드다.
  - 다 찼으면 가장 가까운 선베드에 눕는다(겹침 허용).

### 2.4 튜브
- **대여소:**
  - 바닷가(−12, −7) 근처에 튜브 거치대가 있다.
  - 근처에서 "튜브 빌리기"를 누르면 3종(도넛·플라밍고·수박) 중 하나를 고른다. 무료다.
  - 가지고 있으면 같은 자리에 "튜브 반납" 버튼이 뜬다. 반납은 모래 위에서만 된다.
- **들고 다니기:** 튜브는 허리에 끼운 모습으로 다닌다.
- **바다:**
  - 튜브가 있으면 이동 범위가 앞바다 z −22까지 늘어난다(x는 −28~28).
  - z < −9.5(해안선 너머)에서는 튜브를 탄 자세가 된다: 몸이 물에 반쯤 잠기고 위아래로 흔들리며, 이동 속도는 0.7배.
  - 튜브가 없으면 지금처럼 z −12에서 멈춘다. 처음 한 번 "튜브를 빌리면 더 나갈 수 있어요"를 띄운다.
- 친구 화면에도 튜브와 뜬 모습이 보인다(위치로 판단).

### 2.5 버블풀
- 해변 뒤쪽 오른쪽(중심 약 (9, 14), 크기 8×5m)에 수영장이 있다: 물·흰 테두리·사다리.
- 수영장 안에서는:
  - 몸이 가슴까지 잠긴다(아바타 y −0.9).
  - 이동 속도는 0.6배다.
  - 걷기 동작은 다리 대신 팔 젓기로 한다.
- 비눗방울(반투명 구 스프라이트)이 수면에서 계속 피어올라 터지고, 거품(흰 원판 무리)이 수면에 떠 있다.
- 친구 화면에서도 수영장 안의 사람은 잠긴 모습이다(위치로 판단).
- 놀기 동작과 말풍선은 수영장 안에서도 그대로 된다.

## 3. 저장

- 폰 프로필(localStorage `sunset-resort:v1`)에 추가할 칸:
  - `shells: number` — 정수 0~9999, 기본 3
  - `drink: { cocktail: 0..3, sips: 1..3 } | null` — 기본 null
  - `tube: 'donut'|'flamingo'|'watermelon'|null` — 기본 null
  - `look.face: 'smile'|'round'|'grin'|'wink'|'heart'|'sleepy'` — 기본 smile
- `hydrateProfile`·`normalizeLook`이 이상한 값을 기본값으로 정리한다.
- 기존 `cocktails` 칸은 읽기만 하고 쓰지 않는다(지워도 됨).
- 서버(Supabase DB) 변경은 없다.

## 4. 실시간

- Presence 상태에 `tube`, `drink`를 추가한다(`face`는 look 안). 보내는 시점은 튜브 대여·반납, 잔 사기·다 마시기, 표정 변경뿐이다(사용량 영향 미미).
- 받는 쪽 검사:
  - `normalizeLook`이 face를 정리한다.
  - `tube`는 목록에 없으면 null이다.
  - `drink`는 0~3 정수가 아니면 null이다(받는 쪽에는 잔 색만 필요하고 모금 수는 보내지 않는다).
- 수영장·바다·모래 판정은 보내지 않는다. 받은 x·z로 각자 `placeOf(x, z)`를 계산한다.
- 받은 위치의 범위 검사는 튜브 범위까지 넓힌다(z −22까지).
- 옛 버전과 섞여도 동작한다: 옛 버전은 새 칸을 무시하고, 새 버전은 없는 칸을 기본값으로 둔다.

## 5. 앱 코드

- 새 파일:
  - `src/state/wallet.js`: 조개 얻기·쓰기, 메뉴(이름·색·가격 3), 사기·마시기 규칙. 순수 함수다.
  - `src/scene/places.js`: `placeOf(x, z)`('sand'|'shallow'|'sea'|'pool'), `clampFor(pos, { tube })`, 수영장 사각형, 튜브 바다 범위.
  - `src/scene/shells3d.js`: 조개 12개 놓기·줍기·60초 뒤 재배치.
  - `src/scene/pool.js`: 수영장 메쉬, 비눗방울·거품 이펙트(품질 low면 절반).
  - `src/features/resort.js`: 조개 줍기·석양멍 보상, 바 메뉴, 튜브 대여·반납, 빈 선베드 고르기, 내 아바타의 자세(물속·튜브).
  - `src/ui/resortPanels.js`: 메뉴판, 튜브 고르기.
- 고치는 파일:
  - `src/character/avatar.js`: 표정 6종, 허리 튜브 3종, 잔 보이기/숨기기.
  - `src/scene/props.js`: 선베드 6세트(`points.sunbeds` 배열), 튜브 거치대, 수영장 자리.
  - `src/scene/world.js`·`src/character/player.js`: 이동 범위·속도가 장소와 튜브를 따른다.
  - `src/features/people.js`: 친구의 튜브·잔·표정·물속 자세.
  - `src/net/realtime.js`: 받은 값 검사(tube·drink, 넓힌 범위).
  - `src/app.js`: 칵테일 받기 → resort, 석양멍은 빈 선베드로.
  - `src/ui/entry.js`·`src/ui/panels.js`: 꾸미기에서 칵테일 빼고 표정 넣기.
  - `src/ui/hud.js`: 🐚 배지.
- 학습 문서는 30번부터.

## 6. 오류·예외 처리

- 조개가 모자라면 안내를 띄우고 조개는 그대로 둔다.
- 이미 잔을 들고 있을 때 사면 새 잔으로 바꾼다(메뉴판에 미리 안내).
- 튜브 없이 바다로 가면 z −12에서 멈추고, 첫 1회 안내를 띄운다.
- 바다에서는 반납 버튼이 없다.
- 선베드가 다 찼으면 가장 가까운 곳에 겹쳐 눕는다.
- 수영장·튜브 상태로 석양멍을 시작하면 가장 가까운 빈 선베드로 간다(튜브는 계속 가진다).
- 저장 불가(비공개 모드)면 이번 접속 동안만 유지한다(기존 안내 그대로).
- 저품질이면 비눗방울을 절반으로 줄이고 조개 반짝임을 끈다.
- 실시간으로 받은 이상한 값은 기본값으로 바꾼다.

## 7. 테스트

- 단위:
  - wallet: 시작 3, 줍기 +1, 사기 −3, 부족하면 거절, 마시기 3번이면 빈손, 상한·정수 정리
  - places: 모래·얕은 물·바다·수영장 경계, 튜브 유무에 따른 범위
  - 빈 선베드 고르기: 가장 가까운 빈 자리, 다 차면 가장 가까운 자리
  - profile 정리: face·tube·drink·shells 이상값
  - realtime parsePresence: tube·drink 검사, 넓힌 z 범위
  - avatar: 표정별 부품 보이기, 선글라스와 눈
- 브라우저:
  - 조개 줍기(배지 증가)
  - 바에서 모히또 사기 → 손에 듦 → 마시기 3번 → 빈손
  - 조개 부족 안내
  - 표정 바꾸기와 저장
  - 튜브 빌려 z −20까지 가기, 튜브 없으면 −12에서 멈춤
  - 수영장 들어가면 잠김
  - 친구가 누운 선베드 피하기
  - 창 두 개로 친구의 표정·잔·튜브·물속 보기
- 기존 테스트(SQL·단위 121·e2e 110)를 계속 통과해야 한다. 칵테일 하루 5잔 관련 기존 테스트는 새 규칙으로 바꾼다.
- 배포 후: 내장 브라우저로 확인하고, 사용자와 친구가 폰으로 확인한다.

## 8. 완료 기준

- 혼자서:
  - 조개 줍기 → 바에서 모히또 사기 → 3번 마시기
  - 표정 바꾸기
  - 튜브 빌려 앞바다 떠다니기
  - 수영장 비눗방울
  - 빈 선베드 석양멍
- 두 폰에서 서로의 표정·잔·튜브 탄 모습·수영장에 잠긴 모습이 보인다.
