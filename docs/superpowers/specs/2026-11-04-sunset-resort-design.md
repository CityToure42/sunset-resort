# Sunset Resort (가칭) — 설계 문서

작성일: 2026-11-04 · 상태: 사용자 검토 대기 · 작성: Claude (이세민 님과의 설계 대화 요약)

## 1. 무엇을 왜 만드나

- 목적: 이세민 님이 **앱 개발을 배우는 것**. 코드는 Claude가 전부 작성하고 단계마다 설명을 붙인다(학습 방식 A).
- 참고 앱: The VISL의 **Snow Village · 소원 트리**(thevisl.com/xmas). 브라우저용 3D 웹앱으로, 눈사람이 되어 마을을 걷고 트리에 소원 카드를 걸며, 같은 마을의 다른 사람이 실시간으로 보인다.
- 컨셉 변경: 눈 덮인 크리스마스 마을 → **몰디브풍 해변에서 석양을 바라보며 칵테일을 마시는 힐링**.
- 플랫폼: 아이폰·안드로이드·PC 공통. 원본과 같은 **웹앱**(링크 하나로 열림). 앱스토어 출시는 범위 밖이며, 나중에 Capacitor로 감싸면 가능하다.
- 최종 목표: **C단계(실시간 동시접속)까지.** 구현 순서는 A → B → C이며 각 단계는 별도의 구현 계획으로 진행한다.

| 단계 | 내용 | 서버 |
|---|---|---|
| A | 혼자 쓰는 버전: 해변 걷기, 놀기, 석양멍, 사진, 오늘의 칵테일, 유리병 편지(폰 저장) | 없음 |
| B | 유리병 편지 서버 저장·공유 링크·좋아요·답글·메시지 보기 | Supabase(DB) |
| C | 같은 해변의 다른 사람이 실시간으로 보임 | Supabase Realtime |

## 2. 원본 → 리조트 대응표

| Snow Village | 이 앱 |

| 눈 덮인 마을, 트리 | 해변, 야자수, 수상 방갈로, 바다 위 석양 |
| 눈사람 캐릭터 | 휴양객 캐릭터(밀짚모자·선글라스·하와이안 셔츠·칵테일) |
| 눈멍하기 | 석양멍하기(선베드에 앉아 석양 보기) — 메인 기능 |

| 매일 오후 8시 점등식 | 매일 오후 7시 석양 이벤트(하늘색 변화) |

| 썰매 게임, 어드벤트 캘린더 | 범위 밖 |

## 3. 화면 구성

### 3.1 첫 진입 화면 (A)
- 닉네임 입력칸. 처음엔 자동 생성 추천("나른한 코코넛", "선셋 플라밍고" 등 형용사+명사)이 채워져 있고, 지우고 직접 적거나 "다른 이름 추천" 버튼으로 새 추천을 받을 수 있다.
- 규칙: 앞뒤 공백 제거 후 2~10자, 한글·영문·숫자만 허용. 회원가입이 없으므로 다른 사람과 닉네임이 겹칠 수 있다(허용).
- 꾸미기: 모자 3종(밀짚·버킷·없음), 선글라스 켜기/끄기, 셔츠 색 6가지, 칵테일 4종.
- "해변으로 가기" 버튼. 닉네임·꾸미기는 폰에 저장되어 다음 방문에도 유지되고, 메인의 "꾸미기"에서 언제든 바꿀 수 있다.

### 3.2 메인 화면 (A) — 전체 화면이 3D, 그 위에 얇은 UI
- 상단 왼쪽: 프로필 칩(닉네임 + 꾸미기 버튼). C단계부터 "지금 n명이 함께 있어요".
- 그 아래 배지: "오늘의 칵테일 n/5", "매일 오후 7시 석양 이벤트".
- 상단 오른쪽: "유리병 편지 쓰기", "바다로 가기"(병들이 떠 있는 앞바다로 카메라 이동).
- 하단 탭 5개: 이동하기 / 놀기 / 석양멍하기 / 메시지 보기 / 사진찍기.

### 3.3 기능별 동작
- **이동하기 (A)**: 폰은 화면 아무 곳이나 누르면 그 자리에 가상 조이스틱이 생겨 끌면 걷는다. PC는 방향키·WASD. 카메라는 캐릭터 뒤를 따라가며 드래그로 회전. 이동 속도 2.5 단위/초.
- **놀기 (A)**: 하단에 동작 버튼 5개(인사·건배·춤·눕기·비치볼). 누르면 캐릭터 애니메이션과 이펙트(하트·물방울 등).
- **석양멍하기 (A)**: UI가 사라지고 캐릭터가 선베드에 앉아 칵테일을 든다. 카메라는 선베드 뒤 낮은 앵글로 고정되어 아주 느리게 흔들린다. 파도 소리(버튼으로 시작, 기본은 꺼짐). 화면 아래에 "석양이 지는 동안, 아무것도 하지 않아도 괜찮아요"와 "석양멍 끝내기", 경과 시간(분) 표시. 누적 석양멍 시간은 폰에 저장.
- **유리병 편지 쓰기 (A: 폰 저장 → B: 서버 저장)**: 병 모양 6종(둥근병·긴병·네모병·항아리·하트병·별병) 선택 → 메시지 50자 → "바다에 띄우기" → 앞바다 구역(x −18~18, z −12~−24) 안에서 위치 선택 → "편지가 바다에 띄워졌어요" + 공유 링크. 링크를 연 사람은 그 병 앞에서 시작해 메시지를 읽고 좋아요·답글(50자)을 남긴다(B).
- **메시지 보기 (A: 내 병 목록 → B: 좋아요·답글 포함)**: 내가 띄운 병 목록과 각 병의 좋아요 수·답글.
- **사진찍기 (A)**: 현재 3D 화면을 이미지로 캡처하고 왼쪽 아래에 앱 이름·닉네임 워터마크. 폰은 공유 시트, 없으면 다운로드.
- **오늘의 칵테일 (A)**: 해변 바에서 하루 5잔까지 받는다. 받을 때마다 마시는 동작. 한국시간 자정에 초기화.
- **석양 이벤트 (A: 하늘 연출 → C: 사람들이 모이는 이벤트)**: 매일 19:00 KST에 하늘이 드라마틱 팔레트로 바뀌고 안내가 뜬다.
- **실시간 동시접속 (C)**: 같은 해변의 다른 사람 캐릭터가 닉네임과 함께 보이고, 걷기와 동작이 그대로 보인다.

## 4. 3D 장면 구성

- 하늘: 위·중간·지평선 3색 그라데이션 돔 + 바다에 반쯤 걸린 태양 + 빛무리 스프라이트.
- 바다: 정점을 출렁이게 하는 평면. 해안선(z ≈ −9)에서 −22까지 파도 진폭이 12%→100%로 커져 모래 근처는 거의 평평. 바다 높이는 모래 윗면보다 0.12 낮다.
- 모래: 물결 모양 해안선을 가진 두께 0.6의 해변 덩어리(바다가 모래 위로 비치지 않도록) + 젖은 모래 띠.
- 소품: 야자수 5~6그루, 수상 방갈로 2채와 나무 다리, 선베드·파라솔·사이드테이블(석양멍 자리), 해변 바(오늘의 칵테일), 유리병 구역, 먼 섬 2개.
- 조명: 태양 방향 주광(그림자 맵 1024) + 얼굴 보조광 + 하늘·모래 색 환경광 + 지평선 색 안개.
- 무드 시스템: 하늘 3색·태양색·바다색·안개색·조명색 묶음 3종. 시각에 따라 부드럽게 전환.
  - 파스텔 핑크: 기본(그 외 모든 시간)
  - 골든아워: 18:30~19:00 KST
  - 드라마틱 오렌지·보라: 19:00~19:30 KST (석양 이벤트)
- 캐릭터: 휴양객 한 종류. 상자·구·원기둥 등 기본 도형을 코드로 조립하고 코드로 애니메이션(걷기·인사·건배·춤·눕기·비치볼·마시기). 외부 3D 모델·텍스처 파일 없음. 코코넛·플라밍고 튜브는 "캐릭터 종류 추가" 후보로 범위 밖.
- 카메라: 3인칭 추적(뒤·위), 드래그 회전. 석양멍 모드는 선베드 뒤 고정 저각 + 미세 흔들림.
- 이동 범위: 모래와 발목 깊이 얕은 물. 야자수·방갈로·선베드·바는 원형 충돌.
- 성능 목표: 폰 60fps, 최소 30fps. 첫 3초 프레임을 재서 30fps 미만이면 그림자 끄기·파도 세분화 절반으로 자동 조정. 픽셀 밀도 최대 2배.
- 목업 확인 결과(2026-11-04): 세 캐릭터 후보와 세 무드를 3D로 만들어 비교했고, 휴양객(A)·파스텔 기본을 채택. 바다/모래 겹침 문제는 위 "해변 덩어리 + 해안 파도 감쇠"로 해결 확인.

## 5. 데이터·서버 구조

### 5.1 신원과 저장 (A)
- 회원가입 없음. 첫 실행 때 폰 브라우저에 무작위 **주인 열쇠(UUID)** 생성·저장.
- 폰 저장(localStorage, 키 `sunset-resort:v1`): 열쇠, 닉네임, 꾸미기, 오늘의 칵테일(날짜·횟수), 누적 석양멍 시간, A단계 동안의 내 병 목록.
- 저장소를 못 쓰면(비공개 모드 등) 메모리 임시 모드로 동작하고 안내.

### 5.2 B단계 — Supabase (무료 플랜)
- 표 `bottles`: id(uuid), nickname, avatar(jsonb), shape, message(≤50자), x, z, created_at, likes(int), owner_token(uuid, 비공개).
- 표 `replies`: id, bottle_id, nickname, message(≤50자), created_at.
- 표 `likes`: bottle_id, device_token — 같은 폰에서 한 병에 한 번.
- 규칙(RLS): 누구나 병·답글 추가와 읽기 가능. owner_token은 어떤 조회에도 노출되지 않도록 공개용 뷰로 읽는다. 좋아요는 서버 함수(RPC)로만 증가. "내 병" 조회는 열쇠를 인자로 받는 서버 함수로 처리.
- 검증: 길이 제한과 금칙어 목록을 화면과 DB 양쪽에서 적용.
- 공유 링크: `앱주소/#b=<id>`. 열면 해당 병 앞에서 시작해 카드가 열린다. 없는 id면 "병을 찾을 수 없어요" 후 해변으로.
- 렌더링 상한: 최근 200개 병만 바다에 표시.
- 관리 도구 없음. 문제 게시물은 Supabase 대시보드에서 직접 삭제.
- 무료 프로젝트는 1주일 비활성 시 자동 일시정지되므로, GitHub Actions의 매일 1회 스케줄 작업으로 REST 엔드포인트를 한 번 호출해 깨어 있게 한다.
- 무료 플랜 수치(2026-11 확인): DB 500MB, 월 송출 5GB, 실시간 동시 접속 200, 실시간 메시지 월 200만 건. Pro는 월 $25부터.

### 5.3 C단계 — Supabase Realtime
- 채널 `beach-1`, `beach-2`, …. 입장 시 사람이 가장 적은 채널에 들어가며 한 채널은 최대 30명.
- Presence: 닉네임·꾸미기·현재 위치를 track. "지금 n명" 표시.
- Broadcast: `move`(x, z, 회전) — 움직일 때만, 초당 최대 3회, 가만히 있으면 0회. `emote`(동작 이름) — 동작할 때 1회. 받는 쪽은 보간으로 부드럽게 표시.
- 메시지는 채널의 모든 접속자가 "받은 것"으로 각각 과금되므로 위 상한을 반드시 지킨다.
- 연결 끊김: 상단 "연결 끊김" 표시 후 자동 재접속. 10초 이상 소식 없는 캐릭터는 사라짐.

## 6. 개발·배포 방식

- 코드 위치: 이세민 님 맥 `Future/sunset-resort/`(연결 폴더, 항상 최신본) + GitHub 저장소(백업·배포 원본).
- 호스팅: GitHub Pages. 주소 `https://<아이디>.github.io/sunset-resort/`. 폰에서 "홈 화면에 추가" 가능.
- 배포 절차(선택 B): Claude가 폴더에 저장 → 이세민 님이 GitHub Desktop에서 Commit, Push → 1~2분 뒤 반영. 토큰을 파일로 보관하지 않는다.
- 빌드 도구 없음: `index.html` + CSS + ES 모듈 JS. three.js는 npm에서 받은 복사본을 `vendor/three/`에 넣어 CDN 의존 없이 동작(버전 고정).
- 폴더: `scene/`(해변·하늘·바다·소품), `character/`(캐릭터·동작), `ui/`(화면·버튼·조이스틱), `state/`(저장·닉네임·칵테일·무드 시각), `net/`(B·C 통신), `vendor/`, `tests/`, `docs/`.
- 각 파일 맨 위에 "이 파일이 하는 일" 한국어 주석.
- A단계 중간 결과는 Claude 아티팩트 링크로도 바로 확인 가능. B단계부터는 외부 서버 접속이 필요하므로 GitHub Pages 필수.
- 필요한 계정: GitHub(지금), Supabase(B단계, GitHub 로그인 가능). 둘 다 무료. 가입은 Claude 내장 브라우저에서 함께 진행.
- 앱스토어 출시(Capacitor, 애플 연 $99·구글 1회 $25)는 범위 밖.

## 7. 오류 처리

- WebGL 미지원·라이브러리 로드 실패: "이 브라우저에서는 3D를 켤 수 없어요" 안내 후 중단.
- 저장소 사용 불가: 메모리 임시 모드 + "이번엔 저장이 안 돼요" 안내.
- 저성능: 자동 품질 조정(4절).
- 공유 시트 없음: 다운로드로 대체.
- 병 저장 실패(B): 작성 내용을 폰에 임시 보관하고 재시도 버튼.
- 없는 병 링크(B): 안내 후 해변 진입.
- 입력 검증(B): 길이·금칙어를 화면과 서버 양쪽에서.
- 실시간 끊김(C): 표시·자동 재접속·10초 타임아웃.
- 시각 기준: 자정 초기화와 석양 이벤트는 폰 시계를 그대로 사용.

## 8. 테스트

- 단위 테스트(Node 내장 test runner): 닉네임 규칙·추천 생성, KST 자정 초기화, 시각별 무드, 병 위치 범위, 위치 보간, 금칙어 필터.
- 헤드리스 브라우저 테스트(Playwright): 페이지 로드·콘솔 에러 없음, 캔버스에 그림이 그려짐(픽셀 검사), 탭 5개 모드 전환, 조이스틱 입력으로 캐릭터 이동, 사진찍기가 이미지 생성, 폰(390px)·PC 폭 스크린샷을 Claude가 직접 확인.
